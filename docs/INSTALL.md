Mousey: use one keyboard and trackpad on two Macs

Install it on both Macs.

1. Open Mousey.dmg and drag Mousey onto Applications.

2. Open Mousey from Applications. macOS says it cannot verify the developer, because this build is not signed with a paid Apple account.
   - Click Done.
   - Open System Settings, then Privacy & Security.
   - Scroll to the Security section, click Open Anyway next to Mousey, and confirm with your password.
   You do this once for each download.

3. Follow the tutorial. It takes about two minutes, and it asks for these:
   - Accessibility, so it can read and send keyboard and mouse events.
   - Local network access, and incoming connections if your firewall is on, so the two Macs can find each other. Click Allow.

Both Macs need to be on the same network. If the second Mac has no keyboard or mouse, use Screen Sharing for the first few clicks.

If the pointer stutters over Wi-Fi, turn on Smooth Wi-Fi during the tutorial or in Settings, on both Macs.

To get back at any time, hold Control, Option, and Command, and press Esc.

Your input goes only to the Mac you pair with, encrypted. There is no account, no server, and no analytics. Once a day the app asks GitHub for the latest version number, and you can turn that off in Settings.

To update, do the controlled Mac first, because quitting Mousey there ends your only input to it. If it has no keyboard, turn on Screen Sharing or attach a keyboard before you quit.

To remove it: in Settings, turn off Smooth Wi-Fi if you turned it on, then quit Mousey and delete it from Applications.
